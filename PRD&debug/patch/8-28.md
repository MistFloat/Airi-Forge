## 追加修改
- `workflow.checkpointed` 已从事件类型、磁盘 schema、service switch 中彻底删除。
- 事件日志支持基于 memory cursor 的 gzip 冷归档；内存只保留未投影事件、当前控制状态及最近 200 条消息。[repository.ts](E:/tools/scoop/buckets/airi/apps/stage-tamagotchi/src/main/services/airi/agent-runtime/session-events/repository.ts:132)
- Goal、Schedule、Task、未完成 turn、未结算工具会进入有界热检查点。
- 启动时遗留的 `running` 工具会持久化对账为 `tool.call-reconciled / uncertain`，禁止自动重试。[service.ts](E:/tools/scoop/buckets/airi/apps/stage-tamagotchi/src/main/services/airi/agent-runtime/session-events/service.ts:136)

- IndexedDB 只负责首次导入，不会在重启时把已归档历史重新灌回热日志。

冷归档使用 Node 官方的流式 gzip 和文件持久化接口：[Zlib](https://nodejs.org/api/zlib.html)、[File system](https://nodejs.org/api/fs.html)。
